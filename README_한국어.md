# Counting the same cash 재현 패키지

Zhang, Kang, Sun, Ryu의 Morpho 연구입니다. 기준 원고는 파일명 기준 2026년 11월 1일 22시 버전이며, 변경하지 않은 PDF가 `paper/`에 있습니다. DOCX는 배포하지 않습니다.

기존 Professor Check 재현 패키지에 보존된 기술통계·추가 분석·토론자 검증 자료를 합쳤습니다. 원본 연구 코드, 분석 자료와 추정 결과의 바이트를 보존했습니다. 이번 작업은 포장과 읽기 전용 표 대조이며, 모형 재추정이나 원고·결과 수정은 하지 않았습니다.

Python 3 환경에서 한 명령으로 현재 원고의 16개 번호 표를 대조합니다.

```bash
bash run_all.sh
```

이 명령은 저장된 자료와 표의 표시값을 비교합니다. 새로운 통계 추정을 수행하지 않습니다. 표 1은 보존된 기술통계 CSV, 나머지는 명시적으로 연결된 과거 표 추출본과 비교합니다. 결과는 임시 경로의 `VERIFICATION.csv` 및 `TABLE_SUMMARY.csv`에 저장되며, 제출 시점 결과는 `verify/`에 있습니다. 대조값은 모두 일치합니다. 범위와 한계는 `verify/VERIFICATION_SCOPE.md`에 명시했습니다.

`code/` 및 각 분석 하위 폴더는 기존 연구 프로그램과 분석 자료를 담습니다. `data/`에는 현재 원고 표 추출본과 과거 표 자료, `desc/`에는 여섯 회귀 표본의 기술통계가 있습니다. `addon_package/`는 독립 실행 가능한 추가 분석 자료이며 `optional/table8/`은 기존 차입 사건 회귀 묶음입니다.

자료는 공개 블록체인·공개 API 관측 및 분석 패널입니다. 유료·제한 제공자의 원시 자료와 인증 정보는 포함하지 않았습니다. 전체 API 아카이브와 연산 원장은 기존 소형 패키지에서 생략되었으므로, 보존된 과거 전체 실행기는 새 복제본에서 즉시 완주한다고 보장하지 않습니다. 원래 DOCX가 필요한 구형 검증도 별도 자료가 필요합니다. 자세한 연구 단계와 재실행 안내는 영문 README 및 각 하위 패키지 안내를 따르세요.

파일별 해시는 `FILE_MANIFEST.csv`, 배포 제외 목록은 `EXCLUDED_FILES.md`, 인증 정보 검사 결과는 `SECURITY_SCAN.json`에 있습니다. 단일 파일은 모두 100 MB 이하이며 별도의 Release 첨부 파일은 필요하지 않습니다.
