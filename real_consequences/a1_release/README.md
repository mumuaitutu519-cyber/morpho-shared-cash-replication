# A1 事件清理与描述表

主要表格在 real_consequences/outputs/：
- A1_clean_exclusions.csv：剔除与去重统计。
- A1_clean_by_vault.csv：按金库描述表。
- A3_shared_summary.csv：共用市场低现金状态汇总。
- A1_clean_J_assets_comparison.csv：清理后事件日与非事件日比较。

A1 源文件覆盖 162 个地址、429 次已分类流动性失败调用。筛选条件为请求不超过债权的 101%，债权至少 100 USDC。债权为前一区块末 convertToAssets(balanceOf)，按整数微 USDC 比较。同一所有者、金库及 UTC 小时合并为一个事件，金额和状态取最早保留调用；小时内任一保留调用匹配到失败 UserOperation 即标记。等待为其后同一所有者在同一金库的首笔成功提款，金额不限；截至 2026-03-30 无后续成功提款者为未解决。

A3 与 J/assets 对应原十金库、2025-01-16 至 2026-03-30 的 439 天。共用市场要求同日至少两个样本金库持有正头寸；连续区间按市场分别计算，长度包含首尾合格日末观测。A1 的 ALL 行覆盖全部 162 地址，primary_10 对应原十金库。

## 离线复现

安装 requirements.txt 中的依赖，然后在解压目录运行：

    python real_consequences/code/clean_a1.py

包内包含已分类 A1 输入、429 个精确债权状态的节点响应、失败前状态、对应交易回执、每日状态和全部相关所有者—金库组合的成功调用。events.sqlite 是从源数据库提取的相关成功调用子集，保留该观察期内这些组合的所有成功调用，以核对首次随后成功提款。此包复现清理与描述统计；上游全链失败分类的全部调用轨迹在主复现包中。

脚本离线入口要求债权缓存完整，并省去对包外论文文件的路径检查；统计逻辑与工作区脚本相同。论文文件未放入包，来源哈希保留在 manuscript_hashes.json。本包不运行回归。
