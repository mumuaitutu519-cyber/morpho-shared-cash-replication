# Analysis decisions

- Keep the requested five tasks, outcomes, controls and covariance choices. Publish every fitted specification and all coefficient estimates in the numeric outputs.
- Task 1 uses all 4,380 consecutive changes for 1a/1b. Peer, outside and borrower flows use opening positive-position markets. OwnFlow uses all 33 sample markets; the own component outside the opening set is separately recorded for accounting reconciliation. Column 1c uses the explicit net OwnFlow = 0 criterion. It contains both no-operation days and days with offsetting operations, counted separately.
- Reconcile operation cash flows against independently observed closing cash. Report interest and bad-debt stock-flow terms separately; do not fold them into OutsideFlow or relabel liquidation repayments as voluntary repayments.
- Aggregate Borrow logs within market and transaction. Use earliest log index to order different transactions within the same block. Compare against preceding-block cash using integer arithmetic. Keep the first event and exclude later threshold events within 24 hours of any preceding threshold event.
- Event windows use the ten-vault network at each block. Eligibility is positive position immediately before the borrow; 133 selected borrow events have no sample holder and remain in the event list. Placebos use the same timestamp, same market-supply decile, nearest log supply, and no Borrow on that UTC day. Keep unmatched treated events in the main event sample and list them separately.
- Event outcomes are relative to the preceding block; regression horizon coefficients are relative to -24h. Market outcomes enter once per event-horizon, not duplicated by the number of vaults. The continuous-size model retains the raw borrow/opening-cash ratio, without trimming. Zero opening cash yields an undefined ratio and an explicit exclusion from that specification.
- Ten-vault prediction uses vault/year-month FE. Wild inference uses 9,999 Rademacher draws: restricted wild bootstrap-t for LPM and restricted WCLR-C for logit. Constant-outcome FE groups are removed from logit only and reported.
- Cross-chain Flow follows the same-day definition: committed net inflow from UTC midnight through the frozen snapshot block. Use complete single-vault pagination; multi-address API responses failed an observed-log coverage check and are retained only as diagnostics. Next-state refusal uses the next observed positive-assets state, including zero-S outcomes; zero-S current predictors remain excluded.
- Asset-weighted duplication is sum(assets_v * D_v)/sum(assets_v). Its three undefined dates are excluded from that outcome only. Nine-vault aggregates are recomputed for Spark exclusion. HAC14 columns omit calendar effects as requested. All-version exposure remains unavailable because the archive lacks a complete same-block V2-adapter position universe.
- Market heterogeneity uses the existing shared-market sample, market/date FE and two-way clustering. Split at median vault count 3: <=3 versus >3. Do not change covariance estimates to obtain significance.
- Word and PDF manuscript contents remain unchanged. Deliver one results archive, including numeric tables, paper-facing tables, notes, scripts, source data, report and validation evidence.
