Events are market-transaction borrow amounts exceeding 10% of preceding-block idle cash. An event is excluded if another threshold event occurred in that market during the preceding 24 hours. Vault exposure membership and sharing count are measured immediately before the event. Horizons are -24h, -1h, preceding block, event block, +1h, +6h, +24h, +72h, +168h. Outcomes are relative to the preceding block; regression horizon coefficients additionally use -24h as the reference. Vault outcomes absorb vault-event FE; market outcomes absorb event FE and are entered once per market-event-horizon. SE cluster by event, CR1, t reference G-1. Sharing interactions demean pre-event vault counts across events in each outcome sample. Size interactions use borrow / preceding-block idle cash. Placebo size interactions use the matched borrow event's assigned intensity; actual control borrow is zero. Placebos use the same timestamp, no Borrow in the control market on that UTC date, nearest log supply within the same size decile; unmatched events are listed. Complete nine-horizon pairs are used per outcome. *, **, *** denote 10%, 5%, 1%; parentheses show t statistics.
